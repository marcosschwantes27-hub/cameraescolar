# Referência visual do frontend

Fonte enviada pelo usuário: `C:\Users\amkow\Downloads\DESIGN-notion.md`.

Este documento é referência visual para a próxima etapa de frontend, não uma especificação
funcional e nem autorização para copiar marca ou elementos proprietários do Notion.

## Direção aprovada

- canvas quente `#f6f5f4` e superfícies brancas;
- texto quase preto, com Inter e hierarquia tipográfica compacta;
- azul `#0075de` como única cor estrutural de ação, foco e item ativo;
- bordas `#e6e6e6`, sombras discretas e cartões com raio de 12 px;
- inputs mais retos, com raio de 4 px;
- botões principais em formato pill;
- cores secundárias apenas em ilustrações, ícones ou marcadores decorativos;
- layout responsivo: três/duas colunas no desktop e uma coluna no mobile;
- alvos de toque com no mínimo 44 × 44 px.

Ao implementar, adaptar essa linguagem ao contexto escolar, preservando clareza operacional,
acessibilidade e identidade própria do produto.
